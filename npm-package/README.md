# @macdon3202/impactrail-canonical

This small public package provides an independently retrievable npm Registry
record for ImpactRail V6. Its immutable published version binds the package to
the exact GitHub repository and commit through npm's `repository` and `gitHead`
metadata. Historical download counts are acquired from the official npm
Downloads API by each GenLayer validator.

The package does not claim that a download is a unique user or social impact.
It is one objective adoption signal used alongside commit-pinned GitHub
provenance and bounded semantic classification.
